### Image Quality Notes Flagged for Future Photography Refresh
- Several authentic portraits have small source dimensions (`alice-coulson.jpg` 213×320, `dr-zohair-kaka.bmp` 295×354, `dr-margriet-van-unen.jpg` 299×491, `megan-anjeri.jpg` 318×320, `anna-kaminski.jpg` 346×411, `judy-gitau.png` 400×293 landscape/slightly stretched).
- To keep these authentic portraits sharp and dignified, portrait containers are intentionally sized to a refined editorial scale (~180–240 CSS px width) so low-resolution images are never aggressively upscaled. Higher-resolution headshots can be dropped into `assets/originals/` at any time and re-optimized with `npm run optimize-images`.
